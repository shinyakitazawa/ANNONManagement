# ANNON AI OFFICE — ANON経営参謀 MVP (0.1.0)

ANNON運営向けの**朝の経営ブリーフィング**を中心に、ANON各事業の閲覧範囲を分離し、**担当責任者への委譲承認**を確認できるローカル試作です。

> **重要：これは実運用前の検証版です。** 組織・タスク・決定事項の初期データは架空のサンプルで、実績・合意・契約・入金を表しません。ANONが単一の法人グループであることも意味しません。
> セキュリティ上、**ローカルホストでのみ起動**する仕組みです。インターネット公開・実データ投入・全社利用は、本番向け認証・権限監査・データ取扱いの合意・インフラ構築が完了するまで禁止です。

## すぐ動かす（Node.js 22.13+ / 推奨 Node.js 24 または 26 LTS）

外部パッケージのインストール・Docker・OpenAI APIキーは不要です。Node.js組み込みSQLiteの実験的APIを使用します。

```bash
cd ANNON_AI_Office_MVP
cp .env.example .env
# .env 内の3つのデモパスワードは必要に応じて変更
npm start
```

ブラウザで **http://127.0.0.1:4173** を開きます。

初回起動時、`data/annon-office.sqlite` にデモ組織・ユーザー・タスクが自動作成されます。デモのログイン情報：

| デモユーザー | メール | パスワード環境変数 | 閲覧範囲 |
|---|---|---|---|
| ANNON管理者（デモ） | `annon@example.test` | `ANNON_DEMO_PASSWORD` | デモ全事業（仮付与） |
| 事業責任者（デモ） | `lead@example.test` | `LEAD_DEMO_PASSWORD` | GAD・Lead Label |
| 閲覧担当（デモ） | `viewer@example.test` | `VIEWER_DEMO_PASSWORD` | GAD閲覧のみ |

※実際の役職や各事業の閲覧権限は決め打ちしません。これらは権限制御テストのための架空のユーザーです。

## 動かせる機能

- Webログイン、HttpOnly Cookieセッション、事業スコープの切替
- 許可組織のみのブリーフィング（期限超過・停滞・重要タスク・判断待ち）
- デモタスク・決定事項の閲覧
- タスク新規登録・完了申請 → 別の担当責任者が承認／却下 → 承認後にDB反映
- 権限外組織へのアクセス拒否、申請者本人による自己承認禁止
- AI参謀への質問（APIキーなしはDBからの定型回答／APIキーありはOpenAI Responses API）
- 操作監査ログのDB記録

## OpenAI APIを使う場合

`.env` で次を設定し再起動します：

```env
OPENAI_API_KEY=sk-... # 実キーをリポジトリや社内チャットに貼らない
OPENAI_MODEL=gpt-5.5
```

設定したモデルへのアクセス権があることを確認してください。OpenAIキーはサーバー側だけで使用し、Webブラウザには公開しません。組織ごとに絞られたタスク・決定事項の最小限データのみをモデルへ送ります。APIから回答できなかった場合はエラーを返し、成功したふりはしません。

## 本番化する前に必須

1. Google OIDC + MFAと組織管理者によるプロビジョニング。デモ認証・デモユーザーを削除
2. PostgreSQLへ移行しRLS（行単位アクセス制御）、接続ユーザー権限、事業をまたぐ許可のテストを追加
3. HTTPS、CSRF対策の強化、セッションストア、監査ログの保全、監視・バックアップ、秘密情報管理
4. AIへ送る資料の分類・匿名化・事業単位の同意・外部委託先との条件確認
5. Google WorkspaceとLINEの連携対象・権限・利用者同意・承認ルールを確定
6. 費用上限と障害時の手動運用方法の整備

**今回のMVPはローカルでの業務フロー検証用です。Google Drive/Calendar/LINEへの自動アクセス・自動送信は未実装です。**

## Windows / macOSでの起動ショートカット

- **Windows**：Node.jsをインストールして `start_windows.bat` を実行。起動後、表示されたURLをブラウザで開く。
- **macOS / Linux**：ターミナルから `./start_local.sh` を実行。
- スマートフォンからANNON管理者に共有する場合、このローカルMVPをそのまま公開しないでください。正式な認証・権限・HTTPSを整えた別環境へ移行します。

## TypeScript移行のための型定義

`types/api.d.ts` にAPIの入出力型を用意しています。今回のリポジトリは、追加の依存パッケージなしで起動・検証できることを優先し、実行コードをNode.js ESM（JavaScript）で提供しています。Next.js / TypeScript + PostgreSQLへの置き換えは本番化フェーズで行います。
